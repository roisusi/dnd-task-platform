# Web

React task-flow UI built with Vite, TypeScript and MUI.

## Start

Install dependencies once from the repository root:

```bash
npm install
```

Start only the Web application from the repository root:

```bash
npm run dev:web
```

The Web application runs at `http://localhost:5173` and expects the API to run
at `http://localhost:3000`.

To start both applications together, run:

```bash
npm run dev
```
